# Leire Godoy Psicología · demo de rediseño

Propuesta **no oficial** para valorar un rediseño de la presencia web de Leire Godoy Psicología. La página no recibe ni guarda datos de visitantes. Contiene `noindex, nofollow`.

## Investigación y criterio para hacer la demo

Leire **ya tiene una web** con información abundante: equipo, servicios, proceso terapéutico, tarifas, testimonios y contacto. El rediseño se justifica por una mejora observable en móvil y en la jerarquía de información, no por el uso de Wix. En una visita con navegador de 390 px, la portada actual presentó un ancho de documento de aproximadamente 980 px: navegación, titular y CTA quedaron cortados lateralmente. La página inicial también dedica mucho espacio a mensajes abstractos antes de mostrar claramente las modalidades y cómo contactar. La demo ofrece una ruta breve: quién atiende → tipos de terapia → cómo describe su enfoque → cómo consultar → dónde y cómo contactar.

La web actual sí hace bien varias cosas que conviene preservar: presenta a Leire y a su equipo, publica formación y enfoques, distingue servicios, muestra precios y facilita teléfono, email y WhatsApp. Esta demo no pretende sustituir la profundidad de sus páginas de detalle; enlaza a ellas.

## Diseño y recursos

Concepto: **editorial cálido y sereno**, con crema, rosa empolvado y burdeos, tipografía serif para títulos y sans serif para lectura. La composición separa información factual de llamadas a contacto y evita promesas terapéuticas. La imagen `assets/espacio-conceptual.webp` fue **generada con image_gen** para esta demo, con una estancia arquitectónica vacía; no muestra a Leire ni su consulta. Prompt: estancia contemporánea de paredes crema, sillón tapizado, mesa de nogal, luz natural lateral, sin personas, símbolos médicos, texto, plantas, piedras ni velas. Se declara como conceptual en la propia página.

## Ejecutar localmente

Desde esta carpeta:

```powershell
python -m http.server 8000
```

Abrir `http://localhost:8000/`. No hay instalación ni build.

## QA de la demo

Comprobada con navegador real a 320, 375, 390, 430, 768, 1024 y 1280 px: sin scroll horizontal ni imágenes rotas. Se verificaron el menú móvil (apertura, navegación y cierre), los anclajes internos, teléfono, email, WhatsApp y enlaces a las fuentes; consola sin errores. El HTML mantiene una sola cabecera H1, regiones semánticas, textos alternativos, enlace para saltar al contenido y `noindex, nofollow`. No hay formularios ni scripts de analítica. La página muestra su carácter no oficial y el carácter conceptual de la imagen.

## GitHub Pages

El workflow `.github/workflows/pages.yml` publica la raíz del repositorio al hacer push a `main`. En GitHub, seleccionar **Settings → Pages → Build and deployment → Source: GitHub Actions**. URL esperada: `https://urtxe.github.io/leire-godoy-demo/`.

Antes de una web oficial: confirmar con Leire dirección exacta, horarios, equipo y servicios vigentes, proceso de primera cita, tarifas, textos, fotografía propia y autorizaciones legales. Solo entonces retirar la indicación de demo y `noindex, nofollow`.
